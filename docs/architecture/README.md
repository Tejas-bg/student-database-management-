# Architecture Documentation

This folder holds deeper architecture notes that support the canonical summary in `project-context/SYSTEM_ARCHITECTURE.md`.

## What goes here

- Detailed flow diagrams that are too large for the summary.
- Layer-by-layer implementation notes.
- Integration notes between Flask, MySQL, and the browser.
- Deployment topology diagrams (local demo only for the baseline).

## What does not go here

- The canonical architecture overview. That lives in `project-context/SYSTEM_ARCHITECTURE.md`.
- Decisions. Those live in `docs/decisions/`.
- Database table design. That lives in `database/documentation/`.
