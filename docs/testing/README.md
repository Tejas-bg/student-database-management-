# Testing Documentation

This folder holds test plans, test evidence, and quality reports.

## Planned contents

- Test strategy and scope.
- Test cases for each module.
- Security test results.
- Performance notes.
- Defect log.
- Final regression report.

## Rules

- Record real commands and real results.
- Do not invent pass counts, screenshots, or output.
- Separate automated and manual testing.
- Note skipped tests and why.
- Link to the test files in `tests/`.

## Status

No tests exist yet. Testing starts in Stage 4 and is formalized in Stage 7.
